# TextCooker

Веб-приложение для AI-трансформации стиля текста с использованием локальной LLM (Ollama). Напишите текст, укажите шаблон желаемого стиля — AI перепишет содержимое в этом стиле, всё работает локально.

## Возможности

- **Трансформация стиля** — переписывание текста по шаблону через семантический анализ (cosine similarity эмбеддингов) + LLM
- **Управление документами** — создание, редактирование, версионирование (история коммитов с откатом), экспорт в `.txt`
- **Шаблоны стиля** — сохранение и повторное использование шаблонов (приватные или публичные)
- **Аутентификация** — JWT с ротацией refresh-токенов, хеширование паролей bcrypt
- **История версий** — полная история коммитов со сравнением снэпшотов и откатом

## Технологии

- **Бэкенд:** C# .NET 8 (собственный HTTP-сервер, DI-контейнер, middleware-пайплайн, роутер — без ASP.NET)
- **База данных:** PostgreSQL через Npgsql
- **AI:** Ollama (эмбеддинги: `nomic-embed-text`, LLM: `qwen2.5:3b-instruct`)
- **Фронтенд:** Vanilla HTML/CSS/JS (без фреймворков)
- **Валидация:** FluentValidation
- **Авторизация:** JWT (`System.IdentityModel.Tokens.Jwt`), BCrypt

## Архитектура

Собственная инфраструктура: `HttpListener` → middleware-пайплайн (`ErrorHandling` → `Auth` → `Routing` → `Validator` → `Executor` → `StaticFile`) → контроллеры → engine'ы → репозитории. Собственный DI с constructor injection и детекцией циклических зависимостей.

## Требования

- .NET 8 SDK
- PostgreSQL
- Ollama с моделями `nomic-embed-text` и `qwen2.5:3b-instruct`
